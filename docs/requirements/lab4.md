## Лабораторна робота №4. Використання реляційних БД в Node.js

### Вимоги:

1. Оберіть СУБД (Oracle Database, PostgreSQL, MySQL, MS SQL тощо), встановіть та налаштуйте її.
2. Для завдання з попередньої лабораторної робити створіть базу даних (схему), таблиці та наповніть їх тестовими даними.
3. В проекті з попередньої лабораторної роботи замініть заглушки на реальні компоненти для доступу до даних. 
4. Для операцій з даними в цій лабораторній роботі має використовуватися SQL без використання бібліотек ORM. При цьому:
- принаймні для однієї сутності мають бути реалізовувати усі чотири CRUD-операції (create, read, update, delete);
- операції створення, зміни та видалення даних мають виконуватися транзакційно;
- має бути присутня хоча б одна бізнес-операція, на прикладі якої можна буде продемонструвати підтвердження транзакції у випадку успіху, та відкат транзакції у випадку помилки.
